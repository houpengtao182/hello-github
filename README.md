# hello-github

第一个 GitHub 仓库，用于验证本机与 GitHub 的连接配置。

## 本机环境

- macOS，Git 2.54.0（Apple Git-157）
- 认证方式：SSH（ed25519 密钥，已存入 macOS 钥匙串）
- Git 身份：houpengtao182

## 常用命令

```bash
git status              # 查看改动
git add -A              # 暂存全部改动
git commit -m "说明"     # 提交到本地
git push                # 推送到 GitHub
git pull                # 拉取远端更新
```

## 克隆地址

```bash
git clone git@github.com:houpengtao182/hello-github.git
```
